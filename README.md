# Adam Smajstrla — portfolio

Static site: Home, UX case studies, Illustration, Graphic design, About.

- **Content** lives in `build.py` (case studies, gallery items, bio). Edit it, then run `python3 build.py` to regenerate the HTML.
- **Styles** live in `assets/styles.css`.
- **Images** go in `images/` and are referenced by path in `build.py`.

Hosted with GitHub Pages from the `main` branch.
