# Adam Smajstrla — portfolio

Static site with three sections: UX case studies, Brand (client pages plus selected pieces), and About.

- **Content** lives in `content.py`: case studies, client pages (`CLIENTS`, which group pieces under headings), every piece (`PIECES`), bio.
- Run `python3 build.py` to regenerate the HTML after editing.
- **Styles** live in `assets/styles.css`. **Images** go in `images/`.

Hosted with GitHub Pages from the `main` branch.
